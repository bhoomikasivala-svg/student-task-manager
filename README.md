# Student Task Manager

## Overview
A simple web app to add, view, and complete tasks.  
Built collaboratively by Bhoomika, Urmila, and Jyothi.

## Setup
1. Clone the repo: `git clone https://github.com/your-username/student-task-manager.git`
2. Open `index.html` in a browser.

## Features
- Add tasks
- View tasks
- Mark tasks as complete
